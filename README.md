# 📈 Stock AI

### Machine Learning-Based Stock Analysis & Trading Research System

Stock AI is an experimental **Artificial Intelligence and Machine Learning-based stock analysis system** developed using Python.

The project combines **market-data processing, technical indicators, feature engineering, Machine Learning, trading strategy logic, backtesting, model evaluation, FastAPI, and an interactive dashboard** into a single application.

The primary objective of this project is to demonstrate how Machine Learning and software engineering concepts can be applied to financial-market data for research and educational purposes.

> ⚠️ **Disclaimer:** Stock AI is an educational and experimental project. It does not provide financial advice, guaranteed predictions, or guaranteed investment returns. Financial markets are inherently uncertain, and predictions generated by Machine Learning models may be incorrect.

---

## 🚀 Project Overview

Traditional technical-analysis systems generally rely on manually defined rules and indicators.

Stock AI explores a more complete workflow by combining:

- 📊 Market data
- 📈 Technical indicators
- 🧠 Machine Learning
- ⚙️ Feature engineering
- 🔄 Trading strategy logic
- 🧪 Model evaluation
- 🔁 Backtesting
- ⚡ REST APIs
- 📊 Interactive visualization

The system is designed as a modular project so that individual components such as data processing, feature engineering, Machine Learning, strategies, and APIs can be developed and tested independently.

# 🔐 Environment Configuration

Stock AI uses environment variables for sensitive API configuration.

A template is provided:

```text
.env.example
```

Create your local `.env` file using the template.

### Windows

```cmd
copy .env.example .env
```

Then open it:

```cmd
notepad .env
```

Configure your credentials:

```env
FYERS_CLIENT_ID=your-client-id
FYERS_SECRET_KEY=your-secret-key
FYERS_REDIRECT_URI=http://127.0.0.1/
FYERS_ACCESS_TOKEN=your-access-token
```

### Important Security Rule

Never commit the following to GitHub:

```text
.env
API keys
Secret keys
Access tokens
Authorization codes
Private credentials
```

The `.gitignore` file is configured to prevent sensitive files from being committed.

# 📡 Fyers API Setup

Stock AI contains an authentication workflow for Fyers API integration.

The relevant files are:

```text
login.py
get_token.py
```

## Step 1 — Generate the Login URL

Run:

```bash
python login.py
```

The script generates an authentication URL.

Open the URL in your browser and complete the Fyers login process.

---

## Step 2 — Obtain the Authorization Code

After successful authentication, Fyers redirects to the configured redirect URI.

Retrieve the authorization code from the redirected URL.

Do **not** commit or publicly share the authorization code.

---

## Step 3 — Generate the Access Token

Set the authorization code as an environment variable as described in `get_token.py`.

Then run:

```bash
python get_token.py
```

The script exchanges the authorization code for an access token.

Configure the resulting token through your local environment.
